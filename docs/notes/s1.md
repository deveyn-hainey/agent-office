# S1 (world + art) notes

Files: `js/world/index.js` (API) · `batch.js` (merged geometry+outline batching) · `textures.js` · `building.js` (slab, walls, glass rooms + sliding doors, dotted annotations) · `props.js` (furniture library + decor) · `core.js` (elevator, stairs) · `surfaces.js` (live canvas boards/screens) · `lighting.js` (day/night) · `fx.js` (particles, one draw call) · `debug.js` (dev helper, not imported by the app).

## Contract (§5) — implemented as specified
`floorGroup, floorY, toWorld, slot(s), room(s), surface(s), surfaces.{list,get,update}, setDoor, elevator.{acquire,open,close,moveTo,carPos,doorPos}, stairs.path, fx, pickables, reset`.
* `elevator.carPos()` = car centre `(18.5, y, -11.2)`; `doorPos(f)` = just inside the hall doors `(18.5, floorY(f), -9.75)`. Under `clock.seeking` every elevator/door call snaps and resolves immediately.
* `stairs.path(from,to)`: `[entry(from), S0,E0,S1,E1,…, entry(to)]` – 7 switch-back flights per floor (rise 4 each), world-space, y already absolute. Walkable lanes are z=-9.6 (front) / z=-12.2 (back), x 10.5..14.5. The stairwell and shaft are real holes in the slabs of floors 2–4.
* Surfaces `confscreen/whiteboard/...` render per §5.1. The Slack TV mirrors `slack:message` itself (last 14 messages).
* `fx` kinds: `confetti | steam | puff | sparkle | ballot`; ignored for floors above the currently visible one.

## Additions
* `world.setTimeOfDay(hours|Date|null)` (null/'auto' = real Denver time again), `world.getTimeOfDay()`. Follows the UI `routine:toggle {id:'daynight'}` (off ⇒ fixed noon).
* `world.setDeskScreen(slotId, 'off'|'idle'|'working')` (slot id e.g. `desk-2f-ai-1`, `hot-1f-3`, `desk-1f-reception`). The world also listens to `agent:arrive/depart/status` and switches screens itself (working ⇒ scrolling/flickering code).
* `world.openDoor(id) / closeDoor(id) / autoDoors([{floor,x,z}]) / setRoomInUse(doorOrRoomId,bool)`. The "FREE / IN USE" sign above each glass-room door follows: door open, or any visible agent inside the room rect (polled 2 Hz via `ctx.agents`).
* `world.setAnnotations(true|false|'auto')` – dotted outlines + labels are auto-shown only for the focused floor in floor view.
* `world.setFloorVisibility(topIndex)`, `world.visibleFloors()`, `world.floorVisible(i)`; bus event **`world:floors {upTo, annotFloor}`** whenever it changes (floors above fade out 0.35 s in floor/desk view; S2 already listens). The tall stair/elevator tube is clipped just above the ceiling of the top visible floor.
* `world.drawMural(text,{color,duration}) -> Promise` (placeholder badge, ~3 s stroke animation; instant when seeking), `world.clearMural()`.
* `world.pick(clientX, clientY)` -> `{pick, hit, point}|null` over visible-floor pickables; every surface group also has `userData.surfaceId`. Pickable types: `surface`, `door` (glass door leaves), `room` (invisible floor quad per labelled room).
* Bus events: `door:state {id,open}`, `elevator:state {floor, doors}`, `world:floors`.
* Extra state shapes: whiteboard `columns:[{title,owner?,items:[{sev?,text}]}]` (side-by-side finding lists, use on `board-2f`); `ciwall.badge` string or `{text}`; mural `badge` string or `{text,color}`; slack `ts` ms/s/ISO; confscreen `agent` id or name.
* `world.stats()` -> render calls / triangles (debug).

## Requests / caveats for others
* S0: none needed. The stub contract was enough. Walls are drawn with their inner faces at z=-14.0 / x=-22.0 (0.5 thick, outside the floor rect) so decals at -13.93 / -21.94 sit just in front of them.
* S2: the lying pose should rest at seat height ≈ 0.7 on `sofa-*` slots (cushion tops); desk chairs have seat tops at ≈0.56; monitors/laptops are double-sided glowing panels so the code is visible from the iso camera whichever way the desk faces.
* Draw calls: ~280 world objects across all four floors (≈70 of them are the 11 surfaces); All-floors view measured ≈290 calls including agents.
